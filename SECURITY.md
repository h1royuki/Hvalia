# Security and privacy

Hvalia modifies a narrowly scoped country overlay using an unsupported Apple sync behavior. This is experimental and can fail after an iOS update. It is not a jailbreak or a way to change carrier billing/provisioning.

Please report code vulnerabilities privately through GitHub's repository security reporting feature if enabled; otherwise open a minimal issue without device data and ask for a private contact. Do not include backups, raw phone logs or unique identifiers.

The app has no telemetry, account, remote profile updates or automatic uploads. Local session files can contain private information and are not encrypted by the application. Keep the Mac account secure and retain an offline copy of originals when needed.

Do not use third-party prebuilt “activators” as dependencies or add blind retry logic to a device mutation. Native helpers are developer interfaces, not a hardened boundary against a malicious local user. Private Apple framework APIs may change without notice.
