# Hvalia

**Включение 5G на iPhone в Беларуси**

Hvalia — приложение для macOS, которое помогает включить настройки **«5G вкл.»** и **«5G автоматически»** на iPhone с белорусской SIM. Пошаговый мастер помогает подключить телефон, сохранить исходные настройки, применить изменение и проверить подключение к сети.

## Возможности

- Включение меню 5G для МТС Беларусь и life:).
- Сохранение исходного профиля и восстановление из выбранной копии.
- Отдельная проверка подключения к 5G по данным модема.
- Мастер с восемью этапами включения и шестью этапами восстановления, названиями и иконками шагов слева.
- Отдельные результаты: настройки применены, пункты 5G замечены пользователем, соединение подтверждено модемом.
- Русский, беларуский и английский интерфейсы, светлая и тёмная темы, окно фиксированного размера 720 × 520. Liquid Glass — на macOS 26 и новее.

## Требования и совместимость

- **Mac с Apple Silicon и macOS 14 Sonoma или новее.**
- **iPhone с аппаратной поддержкой 5G**, USB-кабель и доверие к Mac.
- Белорусская SIM/eSIM, подключённая услуга 5G и покрытие оператора.

**Для МТС Беларусь:** на вашем номере должна быть приобретена и подключена услуга **«Интернет 5G»**. Hvalia не подключает эту услугу — её нужно оформить у оператора отдельно.

| Оператор | Статус |
| --- | --- |
| **МТС Беларусь** | Восстановление и применение через приложение проверены на iPhone 15. |
| **life:)** | Предусмотрено применение того же профиля; требуется проверка на реальном устройстве и сети. |

**Hvalia находится в Preview.** Проверенный цикл приложения: iPhone 15, iOS 26.6.2, настройки МТС 70.0. На других моделях и версиях iOS работа не гарантируется. Минимальная версия запуска снижена до macOS 14, но операции с телефоном на macOS 14/15/26 ещё не проверены.

Подробные результаты, версии и ограничения — в [таблице совместимости](docs/COMPATIBILITY.md) и [журнале проверок](docs/VALIDATION.md).

## Как пользоваться

1. Скачайте архив со страницы [Releases](https://github.com/h1royuki/Hvalia/releases), распакуйте и откройте `Hvalia.app`.
2. Подключите и разблокируйте iPhone. Если потребуется, подтвердите доверие на Mac и телефоне.
3. Нажмите **«Включить 5G»** и следуйте инструкциям мастера. Не отключайте кабель во время применения.
4. Перезагрузите iPhone и выберите **«5G вкл.»** в разделе **Настройки → Сотовая связь → нужная линия → Голос и данные**.
5. Запустите проверку сети. Её можно повторить позже из меню приложения без повторного изменения настроек.

Язык переключается в меню **«… → Язык»**: **Русский**, **Беларуская**, **English**. Технические ответы системных помощников могут оставаться на языке источника.

После закрытия последнего окна приложение завершается. При следующем запуске открывается главная; незавершённая запись или повреждённый журнал открывают восстановление.

Текущая сборка подписана ad-hoc и не нотариализована Apple. macOS может заблокировать её открытие. Альтернативный способ запуска — сборка из исходников по инструкции ниже.

### Восстановление

На главном экране выберите **«Восстановить»**, подключите тот же iPhone и выберите сохранённый оригинал. Приложение проверит копию, вернёт исходные байты и попросит перезагрузить телефон.

Hvalia сохраняет затрагиваемые файлы, а не полную резервную копию iPhone. При извлечении оригинал сначала перемещается на телефоне, а затем сохраняется на Mac: прерывание этого этапа может потребовать восстановления. Если операция прервалась, сохраните копии и следуйте [инструкции восстановления](docs/RECOVERY.md).

## Как это работает

Hvalia изменяет три параметра общего профиля Беларуси в `CountryBundles/Overlay`: `Show5GSwitch`, `Enable5GAutoByDefault` и `Enable5GByDefault`. Перед патчем приложение извлекает оригинал с подключённого телефона и сохраняет две проверенные копии. Изменение общего профиля может затронуть обе белорусские линии.

Операторские пакеты и APN остаются прежними. Приложение не подключает услугу у оператора и не добавляет покрытие. Проверка сети использует данные модема; одного переключателя или значка 5G недостаточно для положительного результата.

Техническое описание — в [архитектуре проекта](docs/ARCHITECTURE.md).

## Разработка

Интерфейс написан на SwiftUI, операции и хранение копий — на Swift, подключение к iPhone — на Objective-C с системными фреймворками Apple. Сборка использует Swift Package Manager; сторонних пакетных зависимостей нет.

Нужны Apple Command Line Tools со Swift 6.3, SDK macOS 26+ и Git:

```sh
git clone https://github.com/h1royuki/Hvalia.git
cd Hvalia
./scripts/check.sh
./scripts/build-app.sh
open dist/Hvalia.app
```

Скрипт сборки создаёт приложение и архив в `dist/`. Проверки используют искусственные данные и не изменяют подключённый телефон.

Для просмотра интерфейса без записи на устройство:

```sh
open -n dist/Hvalia.app --args --demo --demo-language be --demo-light
```

## Сообщить о проблеме

Создайте [issue](https://github.com/h1royuki/Hvalia/issues) с версией Hvalia, моделью iPhone, версией iOS, оператором и шагом, на котором возникла ошибка.
