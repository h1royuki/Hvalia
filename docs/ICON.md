# Hvalia application icon

Master: `Resources/AppIcon.png`, 1024 × 1024 PNG with alpha. Generated with the
built-in image generation tool on 2026-09-27. The original white tile variant was
selected by the user. The source was resized with the system `sips` tool.
No generated artwork appears inside the wizard.

`scripts/build-icon.sh` creates ten standard ICNS representations for Finder,
Dock and About.

## Generation prompt

Use case: logo-brand. Create one production macOS application icon for Hvalia, a native utility enabling mobile 5G settings. A bold single sculpted cobalt-blue curling wave, made of smooth translucent glass with restrained cyan edge reflections, centered on a softly rounded square warm-white ceramic macOS icon tile. Front-facing orthographic composition, restrained dimensional depth, clean silhouette and excellent readability at 16 and 32 pixels. Soft studio light from upper left, subtle bevel and very soft contact shadow inside the tile. Tile occupies about 88% of a square 1024 by 1024 canvas. Genuinely transparent pixels outside rounded tile, no backdrop or ground plane. The wave is the only symbol. No phone, documents, text, letters, numbers, badges, checkmarks, logos, watermark, scene, mockup, icon grid or additional objects. Refined native macOS aesthetic, simple and memorable.
