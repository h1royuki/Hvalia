# Hvalia 0.1.0 — experimental preview

**Включение 5G на iPhone в Беларуси**

- Пошаговые мастера включения и восстановления: подключение, доверие, выбор линии/копии, применение, перезагрузка и проверка сети.
- Общий профиль Беларуси для МТС, A1 и life:).
- Две проверенные копии оригинала, сохранение шага мастера и обработка прерванной операции.
- Восстановление после смены SIM; сохранена совместимость с копиями прототипа NRBridge.
- Русский и английский интерфейсы.

## Совместимость

Apple Silicon · macOS 27.0. iPhone 15 / D37AP · iOS 27.0 **24A437** · Belarus Overlay **D37 / 72.0**. Остальные модели и сборки заблокированы. Нужны услуга 5G у оператора и покрытие.

## Что проверено

14 синтетических проверок прошли, включая десять сценариев сбоя. Собранное приложение прошло проверку ad-hoc подписи. Проверены чтение сведений об iPhone и основные экраны. Предшествующий ручной метод подтвердил реальное NR NSA соединение на МТС Беларусь.

**Полный цикл нового приложения на тестовом телефоне ещё не проверен. Реальные подключения A1 и life:) не подтверждены. Проверка клавиатуры и озвучивания VoiceOver не завершена.**

Метод временно перемещает оригинал на iPhone до сохранения копий. При прерывании может потребоваться ручное восстановление. Прочитайте [инструкцию восстановления](https://github.com/h1royuki/hvalia/blob/main/docs/RECOVERY.md).

Архив содержит Hvalia.app для arm64. Подпись ad-hoc, без Developer ID и нотариализации. Для preview предпочтительна самостоятельная сборка из исходников по README. SHA-256 архива находится в SHA256SUMS.txt.
